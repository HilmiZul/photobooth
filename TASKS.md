# Tasks

Daftar tugas untuk dikerjakan oleh Agent. Memuat Fitur, Bug, Update dan Docs.

## Rules

- Uji sampai lolos sebelum commit
- Commit setiap masing-masing perubahan file/new file dengan format:
  - `feat:...` untuk fitur
  - `bug fix: ...` untuk perbaikan bug
  - `update: ...` untuk perubahan UI, layout dan UX writing
- Tahan jangan dulu push ke remote repo
- Buat file CHANGELOG.md jika belum, dan tulis daftar perubahannya dengan format: 
  - `versi - tanggal`
  - diikuti daftar perubahannya/commit
- Commit file TASKS.md ini sesuai perubahannya

## Bug 1: Teks pada hasil foto tidak sesuai saat edit

- Perbaiki layout teks pada hasil foto
- Samakan layout dan spacing teks pada hasil foto dengan saat edit
- Warna teks pada hasil foto tidak sesuai dan tidak terbaca karena warnanya bertabkaran dengan warna bingkai, maka sesuaikan warna teks pada hasil foto dengan warna teks bingkai
- Kerjakan bagian Rules diatas

## Bug 2: Spacing teks terlalu rapat

- Spacing teks terlalu rapat antara judul, tagline dan tanggal
- Tambahkan space dengan mengubah tinggi bingkai agar teks hasil foto sama dengan saat edit. harus sama!
- Kerjakan bagian Rules diatas
